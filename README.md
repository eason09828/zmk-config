# 6 键蓝牙宏键盘 · 制作与固件指南

主控：nice!nano v2（nRF52840）兼容板　｜　固件：ZMK　｜　配置：6 键 + 2 旋钮

---

## 一、接线对照表

> ⚠️ **你这块板上的丝印是芯片原生编号（P0.xx），不是 D 编号。** 下表两列都给了，照着**丝印数字**找焊盘最不容易出错。

| 用途 | 固件里的 D 编号 | 板上丝印 | 板上位置 |
|---|---|---|---|
| 矩阵 行 1 | D4 | `022` | 左列第 8 个 |
| 矩阵 行 2 | D5 | `024` | 左列第 9 个 |
| 矩阵 列 1 | D6 | `100` | 左列第 10 个 |
| 矩阵 列 2 | D7 | `011` | 左列第 11 个 |
| 矩阵 列 3 | D8 | `104` | 左列第 12 个 |
| 旋钮 1 → A | D18 | `115` | 右列第 9 个 |
| 旋钮 1 → B | D19 | `002` | 右列第 8 个 |
| 旋钮 2 → A | D20 | `029` | 右列第 7 个 |
| 旋钮 2 → B | D21 | `031` | 右列第 6 个 |
| 两个旋钮的中间脚 C | — | `GND`（可共用） | — |
| 电池 正极（红） | — | 经拨动开关 → `B+` | — |
| 电池 负极（黑） | — | `B-` | — |

**怎么找焊盘**：板子 USB 口朝上，矩阵和旋钮的焊盘都在左右两列上，逐个对照丝印数字。右列从 USB 那头往下依次是 `B+ / RAW / GND / RST / VCC / 031 / 029 / 002 / 115 / 113 / 114 / 110`。其中 **`RAW` 和 `VCC` 不要接**。

> **这块板的丝印印在焊盘的正下方**（焊盘在上面、字在它下一行）。所以「左列从上往下第 8~12 个」依次就是 `022 / 024 / 100 / 011 / 104`，别数错一位。

**配套图**（在项目根目录，可发到手机边焊边看）：

| 文件 | 内容 |
|---|---|
| `自检与刷机速查卡.png` | 通电前自检 + 焊盘速查 + 刷机 5 步（**焊完先看这张**） |
| `按键与引脚对应图.png` | 6 个按键分别接哪 5 个焊盘（含照片箭头、焊盘放大图、6 键网络图） |
| `单键接线详图.png` | 单个按键的接法：列线 → 轴 → 二极管 → 行线，含二极管正负极 |
| `旋钮接线标注图.png` | 两个旋钮各自 A/B/C 脚对应照片上的哪个焊盘 |

**二极管方向**：每个键串 1 个 1N4148，**黑环端（阴极）朝行线**，6 个方向保持一致（对应固件 `col2row`）。每键一个，共 6 个——**不能一行一列共用一个**，那样会鬼键。

**键位分配**：

```
键1 键2 键3      ← 行1 (022)
键4 键5 键6      ← 行2 (024)
 ↑   ↑   ↑
100 011 104      ← 列1~列3
```

即：键1/键4 同属列1，键2/键5 同属列2，键3/键6 同属列3。

## 二、通电前自检（万用表 · 蜂鸣档）

> 焊接完成后、装电池之前，先测这三项。能提前揪出 90% 的问题。

**① 查短路（最重要）**
黑笔固定按住任意 `GND` 焊盘，红笔依次点这 9 个焊盘：
`022` `024` `100` `011` `104` `115` `002` `029` `031`
期望：**全都不响**。哪个响了就是那个脚和地连锡了，挑开重焊。

**② 测 6 个按键**（红笔接列线、黑笔接行线；反接不通是正常的，因为串了二极管）

| 按键 | 红笔（列） | 黑笔（行） |
|---|---|---|
| 键1 | `100` | `022` |
| 键2 | `011` | `022` |
| 键3 | `104` | `022` |
| 键4 | `100` | `024` |
| 键5 | `011` | `024` |
| 键6 | `104` | `024` |

按住导通、松开断开 = 正常。

**③ 旋钮与电源**
- 两个旋钮的中间脚（C）对 `GND` 应导通；A / B 对 GND 不通（正常）。
- **电池先别接**：插 USB 就能供电测试，等固件刷好、按键全验过再接电池。

**④ 插 USB 看灯**：数据线插到 Mac，板子上的 LED 应该亮起或闪烁。

## 三、编译与刷固件

配置已经准备好，用 GitHub 免费云端编译（本机不用装任何工具链）。

> ⚠️ **必须用官方现行模板建仓库。**
> 旧的 `zmkfirmware/zmk-config-template` 是 2020 年创建、2022 年就停更的废弃仓库，它的 CI 用 `zmk-build-arm:2.5`（4 年前的构建镜像）和已被 GitHub 停用的 `actions/*@v2`，一提交就在 "Set up job" 步骤失败、代码根本轮不到编译。
> 官方现行仓库是 **`unified-zmk-config-template`**，配套的目录结构是 `boards/shields/` + `zephyr/module.yml`（不再用旧的 `config/boards/shields/`）。

1. 打开 `github.com/zmkfirmware/unified-zmk-config-template`，点右上角 **Use this template → Create a new repository**。
   - Repository name 填 `zmk-config`
   - 选 **Public**
   - 点 **Create repository**

   > 用模板建的仓库**不是 fork**，Actions 默认就是启用的，不用再手动点启用。

2. **Code → Add file → Upload files**，把本目录的 **`boards` 文件夹** 和根目录的 **`build.yaml`** **一起**拖进去。
   > ⚠️ 拖的是 `zmk-config` **里面**的 `boards` 文件夹，不要拖最外层的 `zmk-config` 文件夹，否则会多一层目录导致找不到键盘定义。
   > `config/`、`zephyr/`、`.github/` 都不用传，模板自带的已是正确内容。

3. 上传后你的仓库应该长这样：

   ```
   .github/workflows/build.yml    ← 模板自带（已指向新版可复用工作流 @v0.3）
   config/west.yml                ← 模板自带（已锁定 ZMK v0.3）
   zephyr/module.yml              ← 模板自带（board_root: .）
   boards/shields/macropad6/      ← 新增 6 个文件
       macropad6.overlay
       macropad6.keymap
       macropad6.conf
       macropad6.zmk.yml
       Kconfig.shield
       Kconfig.defconfig
   build.yaml                     ← 覆盖模板（模板里那个只有注释、是空的）
   ```

4. Commit → 点上方 **Actions**，等 2~5 分钟跑完（绿勾），进去页面下方 **Artifacts** 下载 `firmware`（zip），解压得到 **`macropad6-nice_nano_v2-zmk.uf2`**。
   > 红叉＝编译报错。回退顺序：`macropad6.zmk.yml` → physical layout 节点 → combos → Studio snippet/conf。

**刷入**：数据线连主控 → **快速双击板上的 RESET 键** → 出现名为 `NICENANO` 的 U 盘 → 把 `.uf2` 拖进去 → 板子自动重启。

## 四、连接 Mac 与改键

**配对**：Mac 蓝牙设置里搜索 **Macropad6** 配对即可。

### 方式一：网页实时改键（推荐，不用重新编译）

固件已内置 **ZMK Studio** 支持，改键全程在浏览器里、即时生效：

1. USB 线连上键盘（Studio 走 USB，最稳）；
2. Chrome 或 Edge 打开 **https://zmk.studio**，点 Connect 选到 Macropad6；
3. **按住 键1 + 键3 一下** 解锁（改完不用保存，自动写入）；
4. 点任意键改绑定，改完立刻生效，重启后依然保留。

> ⚠️ 一旦用 Studio 管过键位，之后**再改 `.keymap` 文件就不会生效**，除非在 Studio 里执行 "Restore Stock Settings" 恢复出厂。

### 方式二：改配置文件重新编译

改 `macropad6.keymap` → 上传到 GitHub → 等 Actions 重新编译 → 下载新 `.uf2` 刷入。

### 方式三：keymap-editor 图形化

浏览器打开 **keymap-editor.com**，关联你的 GitHub 仓库，拖拽改键后它自动提交并触发编译。

## 五、默认功能

| 位置 | 默认功能 |
|---|---|
| 键1 | 播放 / 暂停 |
| 键2 | 上一曲 |
| 键3 | 下一曲 |
| 键4 | 静音 |
| 键5 | 截图（Cmd+Shift+4） |
| 键6 | 锁屏（Cmd+Ctrl+Q） |
| 旋钮 1 | 音量加 / 减 |
| 旋钮 2 | 向下滚动 / 向上滚动（**鼠标滚轮**，任何 App 都能滚）|

> **旋钮 2 用的是鼠标滚轮行为（`&msc`），不是翻页键。** 因为 macOS 上 PageUp / PageDown 只在部分 App 生效（浏览器、编辑器可以，访达 / 桌面 / 系统设置不响应），而鼠标滚轮到哪都能用。
>
> - 滚动手感（转一格滚多少）改 `macropad6.keymap` **最上面**那一行 `#define ZMK_POINTING_DEFAULT_SCRL_VAL 10`：数字改小更细腻（如 6），改大更快（如 15），改完重新编译刷入。
> - 该功能依赖 `CONFIG_ZMK_POINTING=y`（已加在 `macropad6.conf`）。**开启后键盘会多出一个「鼠标」身份，Mac 上必须重新配对一次蓝牙**（系统设置 → 蓝牙 → 忽略/删除 Macropad6 → 重新连接）。
> - 方向反了就说明两个旋钮的 A/B 接法相反：把 keymap 里的 `SCRL_DOWN SCRL_UP` 对调即可。

### 换成别的"按钮功能"

在 `macropad6.keymap` 里把对应位置替换即可（或用 ZMK Studio 直接点）：

| 想要的功能 | 写法 |
|---|---|
| 复制 / 粘贴 / 撤销 / 保存 | `&kp LG(C)` / `&kp LG(V)` / `&kp LG(Z)` / `&kp LG(S)` |
| 鼠标左键 / 右键 / 中键 | `&mkp MB1` / `&mkp MB2` / `&mkp MB3` |
| 音量 / 静音 / 播放 | `&kp C_VOL_UP` / `&kp C_MUTE` / `&kp C_PLAY_PAUSE` |
| 旋钮改成鼠标滚轮 | 已在用：`&inc_dec_scr SCRL_DOWN SCRL_UP`（顺时针 / 逆时针），定义见 `macropad6.keymap` |

## 六、故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 完全无反应（灯不亮） | 电源线只能充电 / 线没插紧 | 换一根**能传数据**的 Type-C 线 |
| 双击 RESET 不出 U 盘 | 数据线不传数据 / RESET 没双击到位 | 换线；按快点、两下之间别停顿 |
| 按一个键出一串键 | 二极管方向反了 | 二极管掉头，或配置改 `row2col` |
| 某个键完全不响应 | 该键支路虚焊 / 二极管坏了 | 万用表测该键通断，重焊或换二极管 |
| 某一行整排不响应 | 该行线虚焊 / 接错脚 | 查该行到 `022`/`024` 通断 |
| 某一列整排不响应 | 该列线虚焊 | 查该列到 `100`/`011`/`104` 通断 |
| 旋钮方向反了 | A/B 接反 | 两根线对调，或在配置里互换 |
| 旋钮完全不动 | 中间脚 C 没接 GND | 检查 C 是否接地 |
| 两个旋钮只有一个能用 | 第二个旋钮接错脚 | 核对 `029` / `031` |
| 改滚轮后 Mac 上完全没反应 | 蓝牙没重新配对（HID 描述符多了一个鼠标） | 系统设置 → 蓝牙 → 删掉 Macropad6 → 重新配对；或改用 USB 线 |
| 蓝牙搜不到 | 固件未刷入 / 未配对 | 确认刷入成功；重新配对 |
| 放一会儿"像死了" | 开启了省电休眠（`CONFIG_ZMK_SLEEP`） | 按任意键唤醒，属正常 |
| ZMK Studio 里看不到键盘 | 固件没编进 Studio / 未走 USB | 确认 `build.yaml` 里的 snippet 已上传；用 USB 连接 |
| ZMK Studio 显示锁定 | 没解锁 | 按住 **键1 + 键3** 一下 |
